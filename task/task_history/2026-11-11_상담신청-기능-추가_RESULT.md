- 계획: 같은 이름의 `_PLAN.md`

## 계획과 달라진 점

- **메일 방식**: 계획 1순위였던 Email Routing의 메일 보내기(send_email)는 Pages Functions에서 지원하지 않음(Cloudflare 문서 확인). 사용자 선택에 따라 **Pages 유지 + Resend**로 구현
- **반복 신청 제한**: IP를 저장하지 않으려고 "같은 연락처로 5분 안에 다시 신청하면 거부"로 구현. IP 단위 제한은 도메인 연결 후 Cloudflare WAF 요청 제한 규칙으로 걸 수 있음(미적용)
- **상태**: 결정 7에 따라 `신규`(기본) / `상담 예정` / `상담 완료` 3가지. 관리자는 상담 예정·상담 완료로만 바꿀 수 있음(신규로 되돌리기 없음)

### 지시별

1. **문의 500자**: `maxlength="500"` + 글자 수 표시(`0 / 500`), 서버에서도 500자 초과 거부
2. **동의 확인**: 체크 안 하고 누르면 폼 안에 "개인정보 수집·이용에 동의해 주세요." 표시하고 전송 안 함. 서버에서도 거부. 동의 문구의 보유 기간을 "상담 완료 후 즉시 파기(미완료 시 최대 1년)"으로 채움
3. **메일 발송**: 저장 후 Resend로 발송(응답 뒤 처리). 제목 `[상담신청] 성함 · 연령대 · 상담 분야`, 본문은 표(신청 일시 KST, 성함, 연락처 전화 링크, 연령대, 상담 분야, 문의 내용) + [관리자 페이지에서 보기] 버튼 + 보유 기간 안내. 텍스트 대체본 포함. 실패해도 신청은 저장되고 관리자 화면에 "발송 실패" 표시. 수신 주소는 비밀 값 `CONSULT_TO_EMAIL`(쉼표로 여러 개 가능)
   - 기존 `sendForm()`의 문자 앱 열기는 제거(결정 3). 연락처 영역의 전화·문자 바로가기는 그대로
4. **네이버 지도**: 상담신청 섹션 "현대해상 경인지역 구월지점"에 `https://naver.me/xX7aoF3h`, 새 탭(`target="_blank" rel="noopener noreferrer"`)
5. **관리자 페이지 `/admin/`**
   - 목록: 최근 신청 먼저(신청 일시 → id 순), 20건씩 [더 보기], 신청 일시·성함·연락처·연령대·상담 분야·상태·보유 기간 표시. 모바일은 카드형
   - 상세: 전체 항목 + 신청 일시 + 상태 변경 일시 + 메일 발송 결과 + 개인정보 보유 기한
   - 상태 변경: [상담 예정] / [상담 완료]
   - 삭제: [신청 내역 삭제] → 확인창 → 영구 삭제(결정 4)
   - 삭제 권장 표시(결정 4): 상담 완료(즉시 파기 대상), 신청 후 1년 초과, 기한 30일 이내(D-n). 목록·상세 모두
   - 저장: D1 `consultations` 테이블

### 보안

- 관리자: Cloudflare Access(Zero Trust) + Functions에서 Access 토큰(RS256) 재검증. 설정 없으면 403. 다른 출처에서 보낸 변경·삭제 요청 403
- 로컬 개발용 우회(`ADMIN_DEV_BYPASS`)는 `localhost`·`127.0.0.1`에서만 동작
- 신청: Turnstile 확인, 서버 입력 검증(성함 30자, 연락처 형식, 연령대·상담 분야 허용값, 문의 500자, 동의, 본문 8KB), Content-Type 검사
- XSS: 관리자 화면은 텍스트 노드로만 표시, 메일은 HTML 이스케이프
- 로그에 개인정보 없음(신청 id·HTTP 상태만)
- 보안 헤더(`nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy`), 관리자 `noindex`·`no-store`, `robots.txt`
- 비밀 값은 Cloudflare 비밀 값으로만(README 절차). 저장소에 이메일·키 없음

## 사용자가 할 일 (README 배포 절차)

1. `npx wrangler d1 create mr-chois-friend-db` → `wrangler.toml` `database_id` 교체 → `npm run db:migrate:remote`
2. Cloudflare Pages에 GitHub 저장소 연결(출력 폴더 `public`)
3. Turnstile 위젯, Access 앱(관리자 이메일), 도메인 구매 후 Resend 도메인 인증
4. 비밀 값 7개 등록: `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY`, `RESEND_API_KEY`, `MAIL_FROM`, `CONSULT_TO_EMAIL`, `ACCESS_TEAM_DOMAIN`, `ACCESS_AUD`
5. 커밋·푸시(지시 시 진행)
